How to use BAID X

A complete guide to the work marketplace for Ghana: who does what, how companies and project managers link up, how workers join projects, and how to message and call from inside the app.

What BAID X is

One place to find trusted people, hire them, run the project, and pay for the work.

Discover

Browse verified workers, companies, project managers and suppliers. Filter by trade and region.

Run projects

Create a project, add a project manager and workers, assign tasks, file reports, approve requests and payments.

Talk

Encrypted messages, photos, files, voice notes, voice calls and video calls.

Get paid

A wallet for earnings and payouts, with project payments recorded against each project.

VerifiedOnly BAID X reviewers decide verification. A paid plan never makes an account verified.

Quick start

  1. Create your account. Open BAID X, tap Profile → Sign up and pick your role. Sign in with your mobile number.
  2. Complete your profile. Follow the checklist on Home. Add your photo and a cover image from Profile → Edit profile.
  3. Get verified. Profile → Verification documents. Upload what is asked and submit. You are notified when a reviewer decides.
  4. Connect. Use Discover (or Jobs for workers), open a profile and tap Message, or accept an invitation under Invitations.
Install itOn a phone, use your browser's “Add to Home screen” so BAID X opens like an app.

Linking a company and a project manager

There are three ways. Pick the one that matches how the two of you already know each other.

Way 1 · The company invites a PM from a project

Best when the company already has a project and wants a specific PM.

  1. Company: Projects → New project. Fill in the name, type, location, dates, budget and the trades needed. Leave “I need a project manager” switched on. The project gets a Project ID such as BXD-PRJ-XXXXX.
  2. Company: open the project → Team → Invite project manager. Search a verified PM by name, specialty or town and select them.
  3. Company: add responsibilities, expected duration and the monthly rate, plus an optional message. Choose which items need the company's own approval, then send.
  4. PM: gets a notification. Open Invitations, read the offer and tap Accept, Decline or Ask a question.
  5. Done. On accept, the PM becomes the project's manager and the project shows both names. A project can have one PM at a time.
Talk firstOpen a PM's card in Discover and tap Message to agree the details, then send the invitation from the project.

Way 2 · The PM links to the company with a join code

Best for a PM who works with a company across many projects and wants a standing link before any project exists.

  1. Company: Profile → Team & join code → Create a code. Share the code with the PM (message it in chat). A new code replaces the old one and lasts 30 days.
  2. PM: Profile → Link a company. Enter the code and tap Request link.
  3. Company: the request shows under Linked project managers. Tap Approve or Decline.
  4. Done. The PM appears as a linked project manager. You can still invite them to individual projects (Way 1).
Link ≠ project roleA link says “we work together.” Being the manager of a specific project is still set by the project invitation.

Way 3 · Through an organization

Best when a company has several staff who all need access (owner, finance, site managers).

  1. Owner: Profile → Organization and open your organization.
  2. Go to Invitations → Invite, enter the person's phone or email and choose a role. You can only grant roles below your own.
  3. Share the generated link. The person opens it while signed in, and joins automatically.
  4. Link a project to the organization so every member with the right role can see it.

The organization has its own members, roles and activity log. See Organizations.

Which one should I use?

SituationUse
New project, you know which PM you wantWay 1
Repeat collaboration across many projectsWay 2, then Way 1 per project

No PM yetCreate the project with “I need a project manager” on, then browse PMs in Discover
Who can do whatOnly the company invites a project manager. A PM can't invite another PM. A project that already has a PM must have that PM removed or finished first.

Adding workers to a project

Both the company and the project manager can invite workers. Workers can also find the project through jobs.

Way 1 · Invite from the Team tab

  1. Open the project → Team → Invite worker. If you have several projects, pick which one at the top of the form.
  2. Search a verified worker by name, trade or town. Select them.
  3. Fill in the trade, daily or monthly rate, expected duration, start date and a message. Tap Send.
  4. The invitation appears in the Team tab with its status: Sent → Accepted or Needs approval.
  5. The worker opens Invitations and taps Accept, Decline or Ask a question.
  6. On accept the worker joins the team and sees the project's tasks under Work.

Way 2 · Talk first, then invite

In Discover, open a worker's card and tap Message to agree rate and dates. Then send the formal invitation from the project's Team tab (Way 1) so the offer is on record.

Way 3 · From a job post

  1. Post a job (Post a job) with trade, place, daily rate and number of workers.
  2. Workers see it in Jobs and tap Apply (their profile must be completed first).
  3. Review applicants, shortlist or accept, then invite the accepted worker into the project (Way 1).

Removing or cancelling

  • Cancel an invitation before it is answered: Team tab → the invitation → Cancel invite.
  • Remove a member who has joined: Team tab → the member → remove.

Approval rules

The company controls how much freedom its PM has when adding workers. This is set per project, in Team (and at project creation).

SettingWhat happens
AutomaticWorkers the PM invites within the plan join as soon as they accept. Anything outside the plan still waits for the company.
Company approvalEvery worker the PM invites waits for the company after accepting.

Always needs the company, even on Automatic

  • Over the planned team size, or more of one trade than planned
  • A role that is not in the project plan
  • Extra budget, sensitive access, supervisor or site-lead roles
  • Anything outside the project requirements

The invitation shows the reasons, so the company knows exactly why it is waiting.

Deciding as a company

  1. Open Approvals from the sidebar (or the banner on the project's Overview).
  2. Under Workers to approve, read the trade, rate and reasons.
  3. Tap Approve to let them in, or Decline.
Money is always yoursExpenses, materials, equipment and payments always need the company's approval, whatever the worker setting is.

A project from start to finish

  1. Create. Company creates the project and gets a Project ID.
  2. Staff it. Invite a PM, then workers (PM, workers).
  3. Plan. PM creates tasks, sets priority and due dates, and assigns them to workers.
  4. Do the work. Workers Accept a task, post updates and photos, then mark progress. Project progress updates automatically as tasks are completed.
  5. Report. The PM files daily or weekly reports (work done, workers present, problems, materials needed). The company reviews and approves or asks for changes.
  6. Request. The PM submits requests for materials, equipment or money. The company approves or declines.
  7. Pay. Payments (worker wages, monthly PM fee) are requested, approved by the company, then marked paid with a reference.
  8. Finish. The PM requests completion. The company checks there are no open tasks, unreviewed reports, or pending requests and payments, then completes the project. Both sides can leave a review.

Worker guide

Set up

  1. Complete the checklist on Home: trade, town, daily rate, payout details.
  2. Add a profile photo and cover image, portfolio photos and certifications (Profile).
  3. Submit verification documents.

Find work

  • Jobs: browse and filter by trade and region, then Apply. Track each application's status (submitted, shortlisted, accepted).
  • Invitations: projects that invited you. Accept, decline or ask a question.

Do the work

  • Work: your projects and tasks. Accept a task, post updates with photos, mark it done.
  • Wallet: balance, earnings and withdrawals to MoMo.
  • Career Growth: experience points and rank tiers earned from completed work and verification.
Stand outA clear photo, a cover image of your best work, and a verified badge get you shortlisted faster.

Company guide

  • Overview: activity across your projects and items waiting for you.
  • Workforce marketplace: search workers and PMs, open profiles, message or invite.
  • Projects: create projects, set budget and approval mode, see team, tasks, reports and finance.
  • Approvals: everything waiting on you: workers, requests, payments, reports and completions.
  • Payments, Equipment, Materials: pay your people and request supplies from suppliers.
  • Team & join code, Organization: link PMs and give your own staff access.
Daily routineOpen Approvals first. Fast approvals keep workers on site and paid on time.

Project manager guide

  1. Get linked. Accept a company's invitation, or use a join code (linking).
  2. Build the team. Team → invite workers by trade, location and rating.
  3. Plan tasks. Tasks → create, assign, set priority and due date.
  4. Report. Reports → daily or weekly, with photos.
  5. Ask for what you need. Finance → submit requests for materials, equipment or money, and payment requests for workers.
  6. Close out. Request completion when everything is done.

The project switcher at the top of each page lets you move between your projects quickly.

Business / supplier guide

  • Catalog: add products and equipment with price, category and availability. Switch items off when out of stock.
  • Inquiries: companies and individuals who ask about your items. Reply in chat.
  • Discover: find companies and PMs to approach directly.
  • Profile: add a logo and cover image, your service areas and delivery range, and switch Accepting orders on or off.

Individual employer guide

  1. Post a job for work at home, with place, rate and the number of people.
  2. Review applicants or browse Discover and message a worker.
  3. Agree details in chat.
  4. Record the person under Hires so you can find them again.

Messaging, files and calls

Messages appear instantly, with no page refresh. Open Chats, pick a conversation or start one from anyone's profile with Message.

Speed

  • Instant send. Your message appears the moment you tap send, then the clock turns into a tick when the server has it. If the network drops, tap the red message to retry.
  • Live receive. New messages, read ticks and “typing” show up on their own. If the live connection is unavailable the app checks again every few seconds.
  • Ticks. ✓ sent, ✓✓ blue read.
  • Unread badge on the Chats tab updates live and clears when you open the chat.

Sending things

To sendDo this
TextType and tap send. Enter sends on a computer; Shift+Enter adds a new line.
Photo, video or fileTap the paperclip, choose one or more files. Photos are resized for speed. Tap a photo to view it full screen, or tap a file to download it.
Voice noteTap the microphone, speak, then tap send. Tap the bin to cancel. Allow the microphone when your browser asks.
Voice call / video callTap the phone or camera icon at the top of the chat. The other person sees an Accept / Decline screen. During a call you can mute and turn the camera on or off.

Call results (duration, declined or missed) are added to the chat so both of you have a record.

End-to-end encryption

Messages and attachments are encrypted on your device before they are sent. Only you and the person you are talking to can read them. BAID X servers and staff only hold scrambled data.

  • Each device creates its own secret key the first time you open Chats. It never leaves the device.
  • The chat header shows End-to-end encrypted when both people have keys.
  • If the other person has not opened Chats yet, the header says Not encrypted yet. Text sent then is stored as normal text until they join. Wait for the lock before sending anything sensitive.
  • Each file gets its own random key, so even stored files are unreadable without the message.

Using a new phone or clearing your browser

Your key lives in your browser. To keep old messages readable after switching devices, create a backup password from the banner at the top of Chats (“Back up your secure-chat key”). On the new device, enter that password at the “Restore secure chat” prompt. If you skip it, new messages work but old ones show “Can't be decrypted on this device.” BAID X cannot recover a forgotten backup password.

Notifications

  • Live in the app. A banner and a soft sound appear for new messages and updates (invitations, approvals, payments, report reviews) while BAID X is open.
  • Browser alerts. In Chats, tap Turn on message alerts and allow notifications. When the BAID X tab is in the background, new messages pop up as system notifications. Tap one to jump to the chat.
  • Badges. The unread count on the Chats tab updates live.
Closed browserAlerts work while BAID X is open in a tab or installed app window. Push notifications to a fully closed phone are not part of this release.

Profile and cover image

  1. Open Profile → Edit profile.
  2. Photo. Choose your profile photo (company logo for companies and businesses).
  3. Cover image. Tap Choose cover image. A preview appears at once. Wide photos work best.
  4. Update your details and tap Save changes.

Your cover shows at the top of your card in Discover and in your public profile. Check it with Profile → How others see you. Photos must be JPG, PNG or WebP, up to 8 MB.

Wallet and payments

  • Balance shows available money, pending money, lifetime earned and a list of every transaction.
  • Withdraw to your mobile money number. Set your payout network, number and account name in Edit profile first.
  • Project payments are requested by the PM, approved by the company, then marked paid with a reference. They show on the project's Finance tab.
AmountsAll amounts are in Ghana cedis (GH₵).

Organizations and teams

An organization lets several people share one company account safely.

  • Roles decide what each member can do. You can only grant a role below your own.
  • Invite with a link from Organization → Invitations. The link works once, for the person it was sent to, and expires.
  • Activity log lists role changes, joins and removals.
  • Two-step sign-in can be turned on from the organization's security area using an authenticator app.

Plans and billing

  • Open Profile → Plans & billing to see your plan, usage and receipts.
  • Payments are made with Paystack (card or mobile money). The plan activates when the payment is confirmed.
  • A paid plan unlocks more capacity and tools. It does not change verification.

For BAID X staff

Staff use the separate admin console at /admin.html. It has dashboards, people and verification queues, projects, jobs, finance, billing, support and an audit log.

  • Access is by staff account only and is checked on the server for every action.
  • Some actions are limited to the Super Admin: managing staff and changing platform settings.
  • Staff cannot read end-to-end encrypted conversations; they only see scrambled content for chats created after encryption was enabled.

FAQ

My message shows a clock and does not send.

You are offline or the connection dropped. Check your network. If the message turns red, tap it to retry.

I can't see the Message button on a profile.

You need to be signed in. Guests see “Sign in to message.”

The PM accepted but can't invite workers.

The invitation must be accepted by the PM first, and the project must still be open (not completed or cancelled).

A worker accepted but is not on the team.

Their invitation is waiting for company approval. Check the company's Approvals page and the reason shown.

The join code was rejected.

Codes expire after 30 days and a new code replaces the old one. Ask the company for a fresh code.

I switched phones and my old chats say “Can't be decrypted.”

Messages are encrypted per device. Restore with your backup password on the new device. Without a backup, only new messages can be read.

I did not get a message alert.

Allow notifications for BAID X in your browser, and tap “Turn on message alerts” in Chats.

Does a paid plan make me verified?

No. Only a BAID X reviewer verifies accounts.
